# Supported RFC Standards Index

The Solas engine implements and adheres to the following RFC specifications:

- RFC 3550: RTP: A Transport Protocol for Real-Time Applications
- RFC 3711: The Secure Real-Time Transport Protocol (SRTP)
- RFC 4566: SDP: Session Description Protocol
- RFC 4585: Extended RTP Profile for Real-time Transport Control Protocol (RTCP)-Based Feedback
- RFC 5104: Codec Control Messages in the RTP Audio-Visual Profile with Feedback (AVPF)
- RFC 5285 / RFC 8285: A General Mechanism for RTP Header Extensions
- RFC 5389 / RFC 8489: Session Traversal Utilities for NAT (STUN)
- RFC 5764: DTLS-SRTP Key Derivation
- RFC 6184: RTP Payload Format for H.264 Video
- RFC 6455: The WebSocket Protocol
- RFC 6464: A Real-time Transport Protocol (RTP) Header Extension for Client-to-Mixer Audio Level Indication
- RFC 7741: RTP Payload Format for VP8 Video
- RFC 8843: Negotiating Media Multiplexing Using the Session Description Protocol (SDP) BUNDLE
- RFC 8851 / RFC 8852: RTP Stream Identifier Source Description and Header Extension
- RFC 8866: SDP: Session Description Protocol (Updated Standard)
- RFC 8888: RTP Control Protocol (RTCP) Feedback for Congestion Control (TWCC)
- RFC 9298: RTP Payload Format for VP9 Video
